# 像训练模型一样学习有机化学

**Human Organic Chemistry Training · 从人名反应到全合成推导**

这是一份由化学竞赛学习经历出发的方法分享：先积累人名反应与经典位点，再用全合成论文和反应软件做遮蔽推导，遇到不确定的问题时猜测可能性、查找定性依据，并优先巩固材料中的常见模式。

本文分享我的学习经历，并整理了一些供读者试用的方法。你可以先读正文，再查看[材料与检索关键词](docs/training-materials.md)，或直接尝试 [Wittig 遮蔽练习](examples/wittig-mask-card.md)。

## 我的学习过程

在学习化学竞赛有机部分时，我首先学习了大量人名反应，记住经典的反应位点。这些知识构成了我做反应题时可以调用的基础。

我会找一些目标产物不太复杂的全合成论文进行训练，也用过 ReactionFlash 和 Chemistry By Design。练习时，我把反应的一部分遮住，尝试推导可能的产物；有时也遮住一个反应物，根据剩余信息反推。

我用过两种信息范围：只看当前底物和试剂条件，推下一步产物；或者遮住一个中间体，保留后续步骤或最终产物，结合前后信息补全路线。

当我推不出来，或者需要重新考虑答案时，我会猜测可能的结果，并进行定性的查找。我知道具体反应位点的选择有专门的定量研究，但对这部分知识了解较少。这里记录的是我实践过的模式识别、推导与定性查证。

我对不同材料的投入也不相同。我优先记住论文、软件和竞赛题里经常出现的反应与产物模式；少见模式的优先级较低，后来可能忘记。我之前把这种常见程度称为“概率高”，这里用“高频模式”表达得更准确。

现在回头看，这段经历与模型训练有一些很直观的相似之处：选择训练材料、从已知样本中构造补全任务，以及通过接触频率和学习投入形成不同的熟悉程度。

## 从反应名称到可以调用的模式

人名反应和经典位点是这套方法的起点。为了让读者更容易复用，可以把一个反应整理成四个问题：

- 哪些结构与条件提示我考虑这个反应？
- 哪个位置可能参与反应？
- 哪些键形成、断裂或改变？
- 什么条件或结构变化会使这个判断需要重新检查？

这是建议采用的整理方式。它把一个名称连接到具体结构，方便之后在全合成路线的分子上使用。

## 怎样选择材料

| 材料 | 内容与入口 | 在项目中的用途 |
| --- | --- | --- |
| ReactionFlash | 人名反应、机理、文献实例与测验；见[开发者介绍](https://apps.apple.com/us/app/reactionflash/id432080813) | 认识和回顾典型反应 |
| Chemistry By Design | 已发表合成序列，以及起始物、试剂或产物预测练习；见[研究组介绍](https://sites.arizona.edu/njardarson-lab/research/) | 在路线中练习已学模式 |
| 全合成论文 | 我会选择目标产物不太复杂的论文 | 自己选择步骤，遮蔽并推导 |

你可以从典型反应入手，再进入合成路线中的实际应用。

“目标产物不太复杂”是一条选题经验，没有固定的分子量、环数或步数阈值。读者可以先选择自己看得懂目标结构、能理解大部分条件的论文，再挑其中适合自己基础的步骤开始。

材料决定自己经常接触什么。复用时，值得说明面向哪类题目、为什么选择这些论文，以及什么模式在自己的材料中反复出现。材料里的高频模式，也需要结合当前底物和条件来判断。

检索时，`organic synthesis` 是较宽泛的起点；寻找全合成路线可以优先尝试 `total synthesis`、`natural product total synthesis` 或 `concise total synthesis`。更多可直接复制的组合见[材料与检索关键词](docs/training-materials.md)。

## 同一个反应，可以从不同方向练习

| 练习形式 | 保留的信息 | 要推导的内容 |
| --- | --- | --- |
| 单步产物预测 | 当前底物、必要试剂与条件 | 下一步产物 |
| 缺失反应物补全 | 产物、其余反应伙伴与条件 | 被遮住的底物或反应伙伴 |
| 路线中间体补全 | 当前步骤信息，以及保留的后续结构或目标 | 满足前后约束的中间体 |

这三种形式我都练过。自己出题时需要明确可见信息：单步预测和看得见后续结构的补全，使用的线索不同。

一个反应可能存在多种合理补全。题目需要提供足够约束，或者明确要求给出一种合理方案。文献里报告的结果是核对的重要依据，但单个产物记录不自动排除所有其他可能性。

## 卡住时：猜测可能性，查找定性依据

我会通过猜测与定性查找处理不确定的题目。为了观察自己的判断怎样变化，你可以保留一份简短记录：

| 记录项 | 可以写什么 |
| --- | --- |
| 原先的猜测 | 我考虑哪个产物或位点，依据是什么 |
| 需要查证的问题 | 我不确定的是反应类型、位点、结构变化，还是条件是否适用 |
| 找到的资料 | 原文、相近实例或反应解释的链接，以及它支持哪一部分判断 |
| 查证后的判断 | 哪个猜测需要修改，哪些地方仍不能确定 |

可以先从原论文对该步的讨论和引用找起，再查相近底物与条件的实例。比较时保留具体差异；相近反应能够帮助判断，但不一定直接解释当前反应的全部选择性。

记录时分清“文献报告了这个产物”“资料给出了这个解释”和“这是我的推测”。查不到决定性依据时，保留问题，也是一份有效的学习记录。查找顺序与记录表是供读者尝试的整理建议，可以按自己的习惯简化。

位点和选择性的定量研究涉及物理有机化学与计算化学等方向。例如，研究者会用计算方法研究竞争反应路径，以及化学、区域和立体选择性的来源；可参见这篇[计算化学与反应选择性的研究综述](https://pubs.acs.org/doi/10.1021/acs.accounts.6b00093)。本文聚焦我实践过的定性推导，定量计算作为拓展阅读。

## 决定哪些模式值得优先巩固

我的取舍是优先记住材料里的高频模式，较少投入少见情况。这里的频率来自个人学习经验，没有做过题库统计。

这与“给定条件下哪个产物生成得更多”是两个不同问题。结构是否复杂、材料里是否常见、具体反应是否偏向某个产物，也需要分别看待。

读者可以保留一个轻量的例外索引：对暂时不重点复习的少见情况，记下来源和一个触发线索，之后需要时再查。这是供读者尝试的整理建议。

## 用模型训练的语言重新理解

| 训练视角 | 这段学习经历中的对应 |
| --- | --- |
| 初始知识 | 大量人名反应与经典位点 |
| 数据选择 | 软件、全合成论文，以及对材料复杂度的筛选 |
| 补全任务 | 遮蔽产物、反应物或路线中间体 |
| 条件预测 | 利用当前结构、试剂条件或路线信息推导 |
| 反馈与外部资料 | 遇到不确定处猜测可能性，查找定性依据 |
| 样本分布与学习投入 | 高频模式反复出现，并获得更多记忆精力 |

化学模型也有给定反应物与试剂预测产物的任务，例如 [Molecular Transformer](https://arxiv.org/abs/1811.02633)。这个视角帮助我们描述训练材料、任务和反馈；它不意味着人脑使用同样的架构，也不能把人的遗忘直接等同于某种模型优化操作。

主动提取知识的设计也可以参考[提取练习研究](https://pubmed.ncbi.nlm.nih.gov/16507066/)。相关实验研究的是其特定学习情境；本项目当前呈现个人方法，尚未测量其对有机推导能力的效果。

## 动手试一张卡

[Wittig：从经典位点到多种遮蔽题](examples/wittig-mask-card.md)

这张卡包括遮产物、遮叶立德、遮羰基底物和换底物练习，也给出一个定性查证示范。它是依据公开反应规律新编的教学示例，不代表我当年的竞赛题或真实错题。

想继续练习，可以利用[检索关键词](docs/training-materials.md)自行寻找合适的材料，从一个熟悉的步骤开始。

若之后记录学习表现，应把同一反应产生的多种遮蔽题视为一组，在独立的新题和延迟复测中观察应用情况。同一题换一个遮蔽位置可以帮助练习，但不足以单独证明已经学会迁移。
