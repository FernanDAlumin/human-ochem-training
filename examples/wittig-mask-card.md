# 示例卡：Wittig 反应的多种遮蔽

这是一组依据公开反应规律新编的教学示例，演示如何从同一个反应生成多种遮蔽题。

这张卡展示“经典位点 → 遮蔽补全 → 定性查证”。先独立作答，再按需展开提示和参考答案。

## 先做题，再展开答案

约定：Ph 表示苯基。题目使用已经形成的磷叶立德，限定在适用的 Wittig 烯化条件下，仅讨论指定底物的目标有机产物。

此处显示反应名方便入门练习；作为混合测评使用时，应移除标题与反应家族提示。

### A：遮住产物

```text
Ph–C(=O)–CH3 + Ph3P=CH2 → [产物]
```

请画出目标有机产物，并标出新双键两端的碳分别来自哪里。

<details>
<summary>提示 1：先定位两个碳</summary>

找到底物的羰基碳和叶立德中直接与磷相连的碳。

</details>

<details>
<summary>提示 2：再检查连接关系</summary>

两者成为新双键的两个端点；原来连在羰基碳上的苯基和甲基保留。

</details>

<details>
<summary>参考答案与检查点</summary>

产物为 `Ph–C(CH3)=CH2`，即 α-甲基苯乙烯。

羰基碳成为连接 Ph 和 CH3 的烯碳；叶立德中的 CH2 成为末端烯碳。副产物为 `Ph3P=O`。末端碳连接两个氢，此例没有 E/Z 异构问题。

分别检查：是否保留原有碳骨架、是否正确连接两个碳、是否错误保留羰基氧。

</details>

### B：遮住叶立德

```text
Ph–C(=O)–CH3 + [叶立德] → Ph–C(CH3)=CH2
```

限定为三苯基膦衍生的 Wittig 叶立德，补全其结构。解释目标产物中新出现的碳片段。

<details>
<summary>参考答案</summary>

`Ph3P=CH2`；它提供目标烯烃中的末端 CH2。

限定试剂家族，是为了让这张卡的补全目标明确。若题干改为开放的合成方案设计，就需要允许其他适用路径并另设评判标准。

</details>

### C：遮住羰基底物

```text
[醛或酮] + Ph3P=CH2 → Ph–C(CH3)=CH2
```

限定通过一次 Wittig 烯化完成，补全羰基底物。

<details>
<summary>参考答案</summary>

`Ph–C(=O)–CH3`，即苯乙酮。将由叶立德提供的末端 CH2 与另一端断开，在保留 Ph、CH3 的碳上恢复羰基。

</details>

### D：换一个底物

在 A 的相同任务约定下，把羰基底物换成环己酮，预测产物，并说明环上原有的碳—碳连接是否改变。

<details>
<summary>参考答案</summary>

亚甲基环己烷：六元环保持，原羰基碳与叶立德提供的 CH2 构成环外双键。

这是一道近迁移练习。前面已经展示了规则，所以它只能观察当前应用情况，不能单独证明长期掌握。

</details>

## 定性查证示范

<details>
<summary>一个假设的错误答案，怎样查证？</summary>

这是为说明方法编写的错误示例，不是作者的真实错题记录。

假设在 A 中猜成了 `Ph–CH=CH2`：

1. **保留原猜测**：先记下这个结构，不用参考答案覆盖它。
2. **提出具体疑问**：原来连在羰基碳上的 CH3 去了哪里？
3. **查找依据**：查看本卡所引 OpenStax 的 Wittig 反应规则，核对原羰基碳与叶立德碳怎样连接。
4. **修正结构**：在此题给定的 Wittig 转化下，原羰基碳上的 Ph 和 CH3 保留，产物应为 `Ph–C(CH3)=CH2`。
5. **记录学到的判断**：这个例子需要检查原子来源与连接关系，尤其是原羰基碳上的取代基。

这一查证支持此题的结构修正，没有计算竞争路径能垒，也没有给其他候选赋予数值概率。更复杂的位点选择问题，可能需要另外查找证据。

</details>

## 一次作答的记录模板

每次练习复制一份填写。反馈前保留原答案，便于区分独立完成与看提示后完成。

```text
日期：
题目：A / B / C / D
反馈前答案：
最优先考虑这个结果的依据（结构、条件或已学反应）：
其他候选及考虑理由（有明确理由时再填）：
关键判断（原子来源、成键位置等）：
把握程度：高 / 中 / 低
提示使用：无 / 1 / 2 / 已看答案
耗时（可选）：
答案核对：正确 / 部分正确 / 错误 / 需要讨论
最早出错的位置：
具体要查证的问题：
查到的资料及链接：
资料支持的修正依据：
查证后修改了什么：
仍只是猜测或尚未解决的地方：
下一次需要练的变化：
这个模式在我的材料中是否常见及判断依据（可选）：
复习优先级与理由（可选）：
```

记录项可以按自己的习惯删减。“把握程度”表示对自己答案的信心，不等于产率或产物比例；本卡不填写没有依据的数值概率。

原子追踪示范和记录格式用于帮助读者把“猜测与定性查找”变成一次可复盘的练习。
